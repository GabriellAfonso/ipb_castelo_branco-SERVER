# Implementation Plan: Structured JSON Logging

**Branch**: `002-structured-json-logging` | **Date**: 2026-06-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-structured-json-logging/spec.md`

## Summary

Add structured JSON logging to the Django API using `python-json-logger` so every log line is a machine-parseable JSON object written to stdout. Introduce a request logging middleware that generates a UUID4 `request_id` per request, propagates it via `contextvars`, and logs request start/end with method, path, status, duration, and user context. The `X-Request-ID` response header enables Android clients to reference specific requests in bug reports.

## Key Design Decisions

### 1. JSON Formatter via `python-json-logger`

Configure in Django's `LOGGING` dictConfig as a custom formatter class. All handlers use this formatter — existing `logger.warning()` / `logger.error()` calls in `custom_exception_handler` automatically output JSON.

See: [research.md](research.md) — Decision 1

### 2. Request ID via `contextvars.ContextVar`

A `ContextVar` in `core/logging/context.py` holds the current `request_id`. A `logging.Filter` reads it and injects into every log record. Thread-safe and async-safe.

See: [research.md](research.md) — Decision 2

### 3. Middleware Position

Second in `MIDDLEWARE` list (after `SecurityMiddleware`). Logs `user_id` in the completion log (after `AuthenticationMiddleware` has run).

See: [research.md](research.md) — Decision 3

### 4. LOGGING Configuration

```python
LOGGING = {
    "version": 1,
    "disable_existing_loggers": False,
    "filters": {
        "request_id": {
            "()": "core.logging.context.RequestIdFilter",
        },
    },
    "formatters": {
        "json": {
            "()": "pythonjsonlogger.json.JsonFormatter",
            "fmt": "%(timestamp)s %(level)s %(name)s %(message)s",
            "rename_fields": {"levelname": "level", "name": "logger"},
            "timestamp": True,
        },
    },
    "handlers": {
        "console": {
            "class": "logging.StreamHandler",
            "stream": "ext://sys.stdout",
            "formatter": "json",
            "filters": ["request_id"],
        },
    },
    "root": {
        "handlers": ["console"],
        "level": "INFO",
    },
    "loggers": {
        "django.request": {"level": "WARNING"},
        "django.server": {"level": "WARNING"},
        "django.db.backends": {"level": "WARNING"},
    },
}
```
